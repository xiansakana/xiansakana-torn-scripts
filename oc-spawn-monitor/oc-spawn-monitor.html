🎯 Torn OC Spawn 监控工具

功能介绍

  • 实时监控 Torn 游戏中新出现的 Organised Crime (OC)
  • 每分钟自动检查一次（可自定义间隔，最短30秒）
  • 发现新 OC 时立即发送桌面通知
  • 显示 OC 详细信息：名称、状态、参与者、时间等
  • 支持移动端滑动手势操作

安装步骤

  1. 安装 Tampermonkey 浏览器扩展
  2. 点击 oc-spawn-monitor_1.0.0.user.js 文件
  3. Tampermonkey 会自动识别并提示安装
  4. 访问 https://www.torn.com
  5. 在页面右侧会看到紫色的 "OC" 按钮（位置在中间偏上）

⚠️ 使用前准备

  • 需要 Torn API Key（权限：FULL）
  • 获取方式：Torn 网站 → Settings → API Key
  • 建议检查间隔设置为 60 秒（1分钟），避免 API 请求过于频繁
  • 需要允许浏览器发送桌面通知

使用方法

  1. 点击页面右侧的 "OC" 按钮打开面板
  2. 输入你的 Torn API Key
  3. 设置检查间隔（默认60秒）
  4. 点击"开始监控"按钮
  5. 脚本会自动每分钟检查一次新的 OC
  6. 发现新 OC 时会：
    • 发送桌面通知
    • 在面板中显示 OC 详细信息
    • 按钮变为黄色表示正在监控

📊 显示信息

每个新 OC spawn 会显示以下信息：

  • OC 名称：如 "Blast from the Past"、"Break the Bank" 等
  • 难度：simple（绿色）/ intermediate（黄色）/ advanced（红色）
  • Scope 数量：使用的 scope 数量（2-4）
  • 发起人：spawn OC 的玩家名称
  • 时间：spawn 时间

脚本监控的新闻格式示例：

  • "MiuPaS used 4 scope spawning the advanced scenario Blast from the Past"
  • "CHaurora used 3 scope spawning the intermediate scenario Leave No Trace"

API 端点

脚本使用以下 Torn API v2 端点：

GET https://api.torn.com/v2/faction/news?striptags=true&limit=100&sort=DESC&cat=crime&key={API_KEY}

通过监控派系新闻中的犯罪类别来检测新的 OC spawn 和就绪状态。

注意事项

  • API Key 会保存在本地，请勿在公共设备上使用
  • 监控期间会持续发送 API 请求，注意 API 使用限制
  • 关闭浏览器或标签页会停止监控
  • 建议在后台保持 Torn 页面打开以接收通知
  • 移动端可以通过从右边缘左滑来显示按钮

技术特性

  • 使用 Torn API v2 监控派系新闻
  • 自动解析新闻内容识别 OC 相关事件
  • 自动去重，只通知新出现的 OC 新闻
  • 支持桌面通知（需要浏览器权限）
  • 响应式设计，支持移动端
  • 数据本地存储，保护隐私
