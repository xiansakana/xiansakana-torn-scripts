## 1.6.18 请求链优化

自动记住 Mod 改为读取当前可见页面及已经发生的配装／Mod 响应：被动观察 fetch、XHR 响应，不主动发起配装读取。配置按武器实例保存，空槽或恢复到一半不会擦掉原组合。Mod1、Mod2 保持在装备按钮下方；安装显示 ✓，再点可卸下，记住的组合保留。

快捷装备优先转发一次原生按钮操作，由 Torn 自己更新原生详情；缓存路径只发送一次装备 POST，更新快捷栏，不再额外读取配装。Mod 装卸只发送一条对应请求；成功、失败和超时都不补查或重试。

物品页“添加物品”右侧提供“导入配置”和“导出配置”。配置文件包含快捷物品顺序、已保存的 Mod 组合和折叠偏好；导入前会完整校验，导入不会自动装备或恢复 Mod，也不会覆盖 API Key、库存缓存或实时装备状态。

资料不够时不会自动补抓。点击“Mod资料”只读取一次可用 Mod，之后需另点 Mod1／Mod2 操作；缓存直连后原生详情如未更新，可单独点击“同步详情”。这两个入口没有串联游戏动作，也不会打开工具箱。库存 ↻ 只查询库存；缺实例时首次点击查询后返回，再次点击才装备。

公司和压价监听遇到失效／禁用 Key 或权限类错误时停止；同一失效 Key 不自动再发送。API 统一间隔 1100ms，支持 Web Locks 的浏览器结合共享时间戳协调本工具箱多标签；没有 Web Locks 时使用当前实例队列及共享时间戳，不能保证跨标签原子排队。其他脚本也共享账户额度，本工具箱不能保证它们的用量。监听改为完成后再安排下一次，停止／换 Key 后不再启动旧任务。界面新增 Key 使用说明和删除保存 Key 按钮；转义公司／第三方行情等文本字段。

构建、语法、compliance-audit.cjs、mods-integration.cjs、items-integration.cjs、toolbox-ui.cjs 本地检查通过。没有连接真实账号操作，也未验证 PDA 或完整持久安装。详细请求证据见 tests/evidence/compliance-audit-1.6.19.json；变更与限制见 tests/evidence/request-chains-1.6.18.md。历史自动实测不构成合规证明，新版也不表示官方审批。

## 实例缓存与原生同步

当前页面和手动查询的实例资料保存七天；缓存不证明实时库存。缺少资料时首次点击只查询，已有资料时一次点击装备或卸下。库存查询仅由用户点击发起；不后台抓取、不自动重试、不在一次装备点击中串联库存查询。

原生按钮路径由 Torn 自行更新装备栏，工具箱不会重复调用更新。1.6.18 缓存路径成功后仅更新快捷栏；原生详情同步改为独立手动点击。原生按钮路径由 Torn 自行更新，不再由脚本自动调用 loadout action。

使用 unsafeWindow 权限访问游戏公开入口，不读取或修改 React 私有字段。实现依据 2026-10-09 登录页面实际加载的 n_items.js EquipFunc 与 loadouts bundle。实际操作仍可能受 Torn 限制或原生确认影响。

## v1.6.1 原生 loadout 同步

服务器确认装备或卸下后，先使用响应中的装备栏；响应不含该区域时读取最新物品页内容，仅同步原生装备栏，不导航或整页刷新。更新图标、名称和属性，保持原生节点事件、loadout 输入值及 TornTools 扩展标记。无法获取可更新的装备栏时明确提示，不将刷新失败误报为装备失败。

新增模拟测试验证切换与卸下后的 loadout 更新、原生按钮事件与节点保留、用户输入保留，以及不弹出工具箱。真实登录页面如使用不同的动态装备栏结构，仍需实际环境验证。

## v1.6.0 无需切分类与卸下操作

参考 NST，装备操作每次先通过 Torn 的只读搜索获取最新实例，再直接发送装备请求，不依赖已加载分类或原生按钮。优先选择当前已装备的实例，实现再次点击卸下；未装备时按帮派、个人、未知来源选择可用实例。

以服务器实际返回的装备／卸下结果更新状态，不盲目标记成功。请求期间锁定按钮，避免连续点击产生重复请求；延迟库存响应不会覆盖刚完成的装备状态。不打开工具箱，也不切换 Torn 分类页。本地缓存仅供展示，操作实例每次重新查询。

## v1.5.2 本地缓存与自动加载

浏览器集成测试：安装 Playwright 后执行 node tests/items-integration.cjs。若使用系统 Edge，设置 PLAYWRIGHT_CHANNEL=msedge；也可使用 Playwright Chromium。

测试使用模拟 Torn DOM 和响应，不连接真实游戏账号，不消耗真实物品。覆盖收藏去重/顺序、使用成功与失败反馈、帮派优先、防重复装备、针与手雷统一切换、非物品页操作提示，以及确认独立切针入口和攻击页监控已移除。1.6.12 的实际验证范围见上文；PDA WebView 尚未验证。
