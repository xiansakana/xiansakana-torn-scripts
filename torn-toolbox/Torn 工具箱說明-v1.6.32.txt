Torn 工具箱說明 v1.6.32（繁體版）

安裝檔案：Torn 工具箱-v1.6.32.user.js。腳本已包含快捷物品模組，不需要額外安裝 NST 或 TornTools。更新後由使用者自行重新整理物品頁。

一、目前功能

購買／出售均價：按來源與時間範圍查詢並彙總交易紀錄。
攻擊篩選：按條件篩選攻擊紀錄，顯示結果及相關連結。
壓價助手／公司監聽：透過官方 API 定期檢查並提示，支援手動停止；API Key 失效或權限錯誤時停止，不自動反覆傳送失效 Key。
語言／時間：支援繁簡切換及 Torn／北京時間切換。

二、快捷物品

手機佈局：600px 及以下顯示緊湊膠囊，以數量和名稱為主，多件同行；隱藏大圖和長庫存文字。數量來自已載入頁面或快取，未知顯示「?」；武器以「✓」表示已裝備。點擊「⋯」顯示配置、資料同步、刪除、重新整理和拖動排序操作，Mod 與子彈按鈕保持可見。桌面保留原卡片佈局。

啟用開關：工具箱中取消勾選 Quick Items 後，物品頁隱藏整個快捷區，移除物品列表的「+」並恢復原生操作區佈局。停用狀態保存在本機，重新整理後不顯示；重新啟用保留收藏與之前的展開／收起狀態。

展開／收起：點擊物品頁「Quick Items · 快捷物品 · 收起／展開」標題切換卡片區，箭頭表示目前狀態。本機保存選擇，重新整理及頁面區域重新產生後恢復。收起保留添加和配置工具列，配置匯入也會同步更新狀態。

1. 添加：物品頁原生 Equip/Unequip 按鈕左側有獨立「+」；按鈕為 18px，操作格為 20px，操作區維持原有寬度，內部緊湊排列。已收藏顯示「✓」。也可透過「添加物品」開啟工具箱，從已載入分類加入收藏。
2. 管理：支援搜尋、刪除、↑↓排序。拖動快捷卡片右下角「⠿」手柄也可排序，放開即保存，頁面收藏列與工具箱同步。
3. 操作：裝備優先使用已載入的原生按鈕；已裝備物品再次點擊卸下。缺少實例資料時首次點擊僅查詢，再次點擊才裝備。確認由使用者手動完成；不自動重試或切換分類。
4. Mod：從目前頁面或已經發生的回應自動記住武器實例的組合。Mod1、Mod2 位於裝備按鈕下方，分別點擊安裝；已安裝顯示「✓」，再點卸下。卸下不清空記住的組合；阻止目前主、副武器間的 Mod 衝突。
5. 子彈：在 Mod 按鈕後面顯示類型簡稱 STD、HP、TR、INC、PI，懸停保留完整名稱。點擊開啟原生選單，再由使用者選擇類型。目前查看另一把武器時先單獨點擊「選擇武器」，再點擊類型簡稱。原生入口未載入時不顯示。
6. Bonus：懸停快捷武器操作按鈕查看已載入的效果與說明，不增加卡片內文字。基於 1.6.27 的識別邏輯增加本機快取，不採用已回退的 1.6.28 原生圖示限定邏輯。
7. Bonus 快取：按武器實例保存，最多 300 個實例。切換分類、卸下或重新整理後仍可查看，標示「上次頁面快取」，不表示即時狀態。已知裝備實例僅匹配自身紀錄；多個歷史實例分別註明來源和編號。未載入說明的物品行不清空舊資料。
8. 配置：物品頁「添加物品」右側有「導入配置」「導出配置」。JSON 包含快捷物品順序、記住的 Mod 組合和折疊偏好。匯入會校驗並替換這些設定，不自動裝備或恢復 Mod。檔案不含 API Key、庫存／實例快取、Bonus 快取和即時裝備狀態。
9. 手動讀取：庫存「↻」只查詢該物品；「Mod資料」單獨讀取一次；「同步詳情」單獨更新原生裝備詳情。裝備與 Mod 按鈕不串聯這些讀取操作。

三、更新紀錄

v1.6.32：參照 PDA 的緊湊排列改造手機快捷物品，增加數量徽標與「⋯」管理入口。通過本機 320/390px 排列、更多選單、數量快取及既有折疊／開關驗證；截圖為模擬資料，未在真實 PDA 內實測。

v1.6.31：統一啟用開關與物品頁顯示，停用時清理添加按鈕與佈局；本機驗證停用後重新整理仍隱藏，重新啟用恢復折疊偏好。

v1.6.30：明確展開／收起入口，補齊狀態提示及配置匯入同步；本機驗證折疊狀態在頁面區域重建與重新整理後保留，展開後更新本機偏好。

v1.6.29：以 1.6.27 為基礎增加武器 Bonus 實例快取，使未裝備或未載入分類的快捷武器可查看歷史懸停提示。
v1.6.28（已回退）：曾將懸停提示限定為原生武器 Bonus 圖示，並區分無／未載入。使用者要求回到 1.6.27，目前版本不採用該改動。
v1.6.27：縮小「+」按鈕，取消擴大原生操作區，改用緊湊、不換行的內部佈局。
v1.6.26：快捷武器增加 Bonus 懸停說明，並隨頁面提示更新。
v1.6.25：去掉按鈕中的「子彈」文字，改用類型簡稱。
v1.6.24：加入裝備按鈕左側的獨立添加格、拖動排序及原生子彈選單快捷入口；當時擴展操作區寬度的佈局已由 1.6.27 替代。
v1.6.19：物品行增加「+」快捷收藏入口；之後嘗試的按鈕定位方案曾回退。
v1.6.18：加入快捷配置 JSON 匯入／匯出。
v1.6.17：取消裝備／Mod 操作的附加讀取鏈；自動記住配置重用已有頁面和回應。失效 Key 停止監聽，API 共用節流，監聽任務避免重疊。

四、驗證與限制

真實登入頁僅透過 Tabbit 唯讀檢查現有結構，未在本輪執行裝備、Mod 或子彈操作。測試使用阻斷／攔截全部網路的本機模擬頁面。
1.6.29 已通過建置、語法及 quick-controls.cjs：涵蓋按鈕佈局、子彈簡稱、拖動排序，以及 Bonus 快取在物品行移除與模擬重新整理後保留。不能將舊版本測試紀錄寫成目前版本完整實測。
PDA 與腳本管理器完整持久安裝尚未實測。頁面結構變化可能影響入口。功能實作與本機測試不代表 Torn 官方審批。
