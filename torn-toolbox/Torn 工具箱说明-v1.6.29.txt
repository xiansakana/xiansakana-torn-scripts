Torn 工具箱说明 v1.6.29（简体版）

安装文件：Torn 工具箱-v1.6.29.user.js。脚本已包含快捷物品模块，不需要额外安装 NST 或 TornTools。更新后由用户自行刷新物品页。

一、当前功能

购买／出售均价：按来源与时间范围查询并汇总交易记录。
攻击筛选：按条件筛选攻击记录，显示结果及相关链接。
压价助手／公司监听：通过官方 API 定期检查并提示，支持手动停止；API Key 失效或权限错误时停止，不自动反复发送失效 Key。
语言／时间：支持繁简切换及 Torn／北京时间切换。

二、快捷物品

1. 添加：物品页原生 Equip/Unequip 按钮左侧有独立“+”；按钮为 18px，操作格为 20px，操作区保持原有宽度，内部紧凑排列。已收藏显示“✓”。也可通过“添加物品”打开工具箱，从已加载的分类加入收藏。
2. 管理：支持搜索、删除、↑↓排序。拖动快捷卡片右下角“⠿”手柄也可排序，放开即保存，页面收藏栏与工具箱同步。
3. 操作：装备优先使用已加载的原生按钮；已装备物品再次点击卸下。缺少实例资料时首次点击只查询，再次点击才装备。确认由用户手动完成；不自动重试或切换分类。
4. Mod：从当前页面或已经发生的响应自动记住武器实例的组合。Mod1、Mod2 放在装备按钮下方，分别点击安装；已安装显示“✓”，再点卸下。卸下不清空记住的组合；阻止当前主、副武器间的 Mod 冲突。
5. 子弹：在 Mod 按钮后面显示类型简称 STD、HP、TR、INC、PI，悬停保留完整名称。点击打开原生选择菜单，再由用户选择类型。当前查看另一把武器时先单独点击“选择武器”，再点击类型简称。原生入口未加载时不显示。
6. Bonus：悬停快捷武器操作按钮查看已加载的效果和说明，不增加卡片内文字。基于 1.6.27 的识别逻辑添加本地缓存，不采用已回退的 1.6.28 原生图标限定逻辑。
7. Bonus 缓存：按武器实例保存，最多 300 个实例。切换分类、卸下或刷新后仍可查看，标注“上次页面缓存”，不表示实时状态。已知装备实例仅匹配自身记录；多个历史实例分别注明来源和编号。未加载说明的物品行不清空旧数据。
8. 配置：物品页“添加物品”右侧有“导入配置”“导出配置”。JSON 包含快捷物品顺序、记住的 Mod 组合和折叠偏好。导入会校验并替换这些设置，不自动装备或恢复 Mod。文件不含 API Key、库存／实例缓存、Bonus 缓存和实时装备状态。
9. 手动读取：库存“↻”只查询该物品；“Mod资料”单独读取一次；“同步详情”单独更新原生装备详情。装备与 Mod 按钮不串联这些读取操作。

三、更新记录

v1.6.29：以 1.6.27 为基础增加武器 Bonus 实例缓存，使未装备或未加载分类的快捷武器可查看历史悬停提示。
v1.6.28（已回退）：曾将悬停提示限定为原生武器 Bonus 图标，并区分无／未加载。用户要求回到 1.6.27，当前版本不采用该改动。
v1.6.27：缩小“+”按钮，取消扩大原生操作区，改用紧凑、不换行的内部布局。
v1.6.26：快捷武器增加 Bonus 悬停说明，并随页面提示更新。
v1.6.25：去掉按钮中的“子弹”文字，改用类型简称。
v1.6.24：加入装备按钮左侧的独立添加格、拖动排序及原生子弹菜单快捷入口；当时扩展操作区宽度的布局已由 1.6.27 替代。
v1.6.19：物品行增加“+”快捷收藏入口；之后尝试的按钮定位方案曾回退。
v1.6.18：加入快捷配置 JSON 导入／导出。
v1.6.17：取消装备／Mod 操作的附加读取链；自动记住配置复用已有页面和响应。失效 Key 停止监听，API 共用节流，监听任务避免重叠。

四、验证与限制

真实登录页仅通过 Tabbit 只读检查现有结构，未在本轮执行装备、Mod 或子弹操作。测试使用阻断／拦截全部网络的本地模拟页面。
1.6.29 已通过构建、语法和 quick-controls.cjs：覆盖按钮布局、子弹简称、拖动排序，以及 Bonus 缓存在物品行移除和模拟刷新后保留。不能将旧版本的测试记录写成当前版本完整实测。
PDA 与脚本管理器完整持久安装尚未实测。页面结构变化可能影响入口。功能实现与本地测试不代表 Torn 官方审批。
